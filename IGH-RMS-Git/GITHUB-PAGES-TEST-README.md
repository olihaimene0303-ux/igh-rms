# IGH-RMS GitHub Pages Test Deployment V1.0

This package is prepared for a free GitHub Pages test deployment of the IGH-RMS website.

## Upload structure

Keep the folder structure exactly as supplied:

- `index.html` — homepage
- `assets/` — CSS and logo assets
- `pages/` — all website pages
- `docs/` — deployment and QA documentation
- `robots.txt`, `sitemap.xml`, `_headers` — supporting production files
- `.nojekyll` — tells GitHub Pages to serve the static site without Jekyll processing

## Recommended GitHub repository

Create a public repository such as `igh-rms-website-test`, upload the contents of this package to the repository root, and enable GitHub Pages from the `main` branch and `/ (root)` folder.

## Important

GitHub Pages is being used here as a test/staging host. Do not place passwords, private credentials, sensitive client information, or confidential documents in this repository.

The current contact/enquiry functionality should be tested before any public production launch.
