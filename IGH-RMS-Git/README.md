# IGH-RMS Gateway Harmonization & Practice Integration V1.2

Production-ready static website package for IGH-RMS.

## Architecture
- `index.html` — unified homepage and visitor gateway
- `pages/what-we-do.html` — complete practice architecture
- `pages/insights.html` — research and knowledge gateway
- `pages/resources.html` — resource gateway
- `pages/contact.html` — engagement gateway
- Core practice pages — governance, development/MEL, strategy, research, training, digital, investment/business, project management
- Strategic input pages — professional expertise, research/knowledge, finance, digital technology, strategic partnerships, governance, human capital, innovation, standards
- Integrated advisory pages — diagnostics, strategic planning, organizational design, capacity development, systems/SOPs, performance management
- Research & knowledge pages — applied research, evidence synthesis, data analysis, knowledge management, learning products, research capacity
- `assets/style.css` — shared responsive design system
- `assets/IGH-RMS-logo.png` — corporate logo

## Visitor Journey
Home → What We Do → Practice Page → Engage IGH-RMS
Home → Insights / Resources → Engage IGH-RMS
All practice pages link back to What We Do and Contact.

## Deployment
Upload the contents of this folder to any standard static web host. No build step or server-side dependency is required.

## QA
V1.2 includes link validation, consistent navigation, responsive layout, semantic headings, descriptive page titles/meta descriptions, local assets and a single shared stylesheet.
