This package is derived directly from the actual IGH-RMS V1.2 production baseline. Existing practice pages and architecture have been preserved. V1.3.1 adds production launch controls rather than redesigning the site.

- Domain: `igh-rms.com`
- Primary mailbox: `ighconsulting@igh-rms.com`
- Hosting: Cloudflare Pages
- Analytics: Cloudflare Web Analytics
